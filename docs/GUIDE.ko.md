# HanFix 사용 가이드

이 문서는 설치부터 일상 사용, 문제 해결까지 순서대로 설명합니다.
명령어를 몰라도 1~3장만 읽으면 쓸 수 있습니다.

---

## 1. 설치 (3분)

1. GitHub Releases에서 `HanFix-1.1.0.dmg`를 내려받습니다.
2. DMG를 더블클릭하면 창이 열립니다.
3. **HanFix.app**을 오른쪽 **Applications** 폴더로 끌어다 놓습니다.
4. Launchpad나 응용 프로그램 폴더에서 HanFix를 실행합니다.

**처음 실행할 때만** "확인되지 않은 개발자입니다" 창이 뜰 수 있습니다.
이때는 앱을 **우클릭 → 열기 → 열기**를 누르면 됩니다. 한 번 허용하면 다음부터는
그냥 열립니다. (애플 개발자 유료 인증서로 공증하지 않은 오픈소스 앱에서 흔한 절차입니다.)

> 파이썬, Homebrew, Xcode 같은 것을 설치할 필요가 없습니다. 필요한 런타임이 앱 안에 들어 있습니다.
> 요구 사항: macOS 13 이상, Apple Silicon 또는 Intel.

---

## 2. 첫 설정 (1분)

앱을 열고 오른쪽 위 **설정**을 누릅니다 (단축키 `⌘,`).

![설정 화면](settings.png)

- **감시할 폴더** — 자동으로 정리할 폴더입니다. 기본은 `~/Downloads`, `~/Desktop`, `~/Documents`.
  `폴더 추가…`로 원하는 폴더를 더할 수 있고, `−` 버튼으로 뺄 수 있습니다.
- **로그인할 때 자동 시작** — 켜두면 맥을 재부팅해도 자동으로 다시 켜집니다. **켜는 것을 권장**합니다.
- **코드/프로젝트 폴더 보호** — git 저장소나 Xcode 프로젝트 내부는 건드리지 않습니다. 켜두세요.
- **대기 시간** — 기본값을 그대로 두세요. 파일을 쓰는 중에 이름을 바꾸면 안 되기 때문에
  조금 기다렸다가 처리합니다.

**저장**을 누르면 끝입니다. 이후로는 아무것도 하지 않아도 됩니다.

### 2-1. 폴더 접근 권한 (처음 한 번, 세 폴더만)

macOS가 막는 폴더는 **다운로드·데스크탑·문서 세 개뿐**입니다.
`~/작업`, 외장 디스크처럼 **그 밖의 폴더는 권한 없이 바로 동작**하므로,
문서를 그런 폴더에 두고 쓰신다면 이 단계를 통째로 건너뛸 수 있습니다.
(실측: 보호 밖 폴더는 권한 대화상자 없이 즉시 감시 시작)

세 폴더를 감시하려면 macOS가 백그라운드 앱의 접근을 막기 때문에 허용이 필요합니다.
화면에 **"HanFix이(가) 다운로드 폴더의 파일에 접근하려고 합니다"** 창이 뜨면 **허용**을 누르세요.
세 폴더 각각 물어볼 수 있습니다.

창이 뜨지 않거나 감시가 시작되지 않으면, 아래처럼 직접 허용합니다 (한 번만):

1. **시스템 설정**을 엽니다.
2. **개인정보 보호 및 보안** → **전체 디스크 접근 권한**으로 들어갑니다.
3. 왼쪽 아래 **+** 를 누르고, **응용 프로그램** 폴더의 **HanFix**를 선택해 추가합니다.
4. 토글이 켜져 있는지 확인하고, 앱을 다시 실행합니다.

> 이 권한이 없으면 앱은 아무 파일도 건드리지 않고 대기합니다(파일을 건드리지 않습니다).
> 앱 창 아래에 **권한 필요** 표시가 뜨면 이 단계를 하라는 뜻입니다.
>
> 앱을 새 버전으로 교체하면 서명이 바뀌어 권한이 초기화됩니다. 업데이트 후 한 번만 다시
> 켜주세요. (유료 개발자 인증서로 공증하면 이 과정이 사라집니다.)

## 3. 일상 사용

### 3-1. 자동 (대부분의 경우)

설정한 폴더에 파일이 생기면 **3~5초 안에** 이름이 조용히 정리됩니다.
다운로드 폴더에 받은 파일, 다른 폴더에서 옮겨온 파일, 새로 저장한 문서 모두 해당됩니다.
사용자가 할 일은 없습니다.

메뉴 막대에 HanFix 아이콘이 떠 있으면 정상 동작 중입니다.
아이콘을 누르면 `일시정지`, `로그 보기`, `자동 감시 끄기`를 쓸 수 있습니다.

### 3-2. 수동 (이미 쌓인 파일 정리)

자동 감시는 **앞으로 생기는 파일**만 다룹니다. 예전에 받아둔 파일이 있다면 한 번 정리하세요.

1. 폴더를 HanFix 창에 **끌어다 놓습니다**.
2. 목록에 `NFD` 배지가 붙은 항목이 보입니다. `→` 오른쪽이 바뀔 이름입니다.
3. **전체 이름 정리**를 누릅니다.
4. 잘못됐다면 **되돌리기**를 누르면 원상복구됩니다.

> 끌어다 놓는 것만으로는 아무것도 바뀌지 않습니다. 스캔만 하므로 안심하고 확인하세요.

### 3-3. 압축해서 보내야 할 때

여러 파일을 zip 하나로 묶어 보내는 경우에만 해당합니다.

1. 폴더를 앱에 놓고 **전체 이름 정리**를 먼저 합니다.
2. **윈도우용 압축**을 누릅니다. 같은 위치에 `폴더이름.zip`이 만들어집니다.

**Finder의 `압축` 기능은 쓰지 마세요.** 이름은 그대로 담지만 "이 이름은 UTF-8"이라는
표시를 넣지 않아서, 받는 사람이 윈도우 기본 기능으로 풀면 글자가 깨질 수 있습니다.

### 3-4. 받은 zip이 깨져 보일 때

zip을 앱에 끌어다 놓으면 버튼이 **안전하게 풀기**로 바뀝니다. 누르면 CP949로 만들어진
옛 압축이나 NFD 이름이 들어 있는 압축도 한글 이름으로 복원해서 풀립니다.

## 4. 문제 해결

### "확인되지 않은 개발자" 라고 나옵니다
앱을 우클릭 → 열기 → 열기. 또는 시스템 설정 → 개인정보 보호 및 보안 → 하단의 "확인 없이 열기".

### 자동 감시가 안 되는 것 같습니다
1. 메뉴 막대에 HanFix 아이콘이 있는지 확인합니다. 없으면 앱을 한 번 실행하세요.
2. `hanfix watch --status` 로 상태를 봅니다.
3. `~/.hanfix/watch.log` 마지막 줄을 확인합니다.
   - `접근 거부` : 권한 문제. 앱을 응용 프로그램 폴더로 옮긴 뒤 설정에서 다시 저장하세요.
   - `건너뜀(project)` : 코드 폴더라 보호된 것입니다. 정상입니다.

### 로그인할 때 자동 시작이 안 됩니다
설정에서 **로그인할 때 자동 시작**을 껐다가 다시 켜고 저장하세요.
앱을 응용 프로그램 폴더가 아닌 곳(DMG 안, 다운로드 폴더)에서 실행하면 등록되지 않습니다.

### NAS에 올린 파일이 맥에서 안 열립니다
맥의 SMB 클라이언트가 전송할 때 이름을 NFC로 바꾸기 때문에, 서버에 NFD로 저장된 파일은
열리지 않습니다(error -43). 이건 맥에서 고칠 수 없고 **NAS 쪽에서** 이름을 바꿔야 합니다.

### 외장 하드디스크에서 정리가 안 됩니다
그 디스크가 HFS+로 포맷되어 있으면 파일시스템이 NFD를 강제하므로 이름을 바꿔도 되돌아갑니다.
HanFix는 이 경우 작업을 거부하고 알려줍니다. APFS나 exFAT로 다시 포맷하면 해결됩니다.

## 5. 명령줄 (선택)

앱 없이 터미널에서도 쓸 수 있습니다.

```bash
H="/Applications/HanFix.app/Contents/Resources/hanfix/bin/hanfix"

$H scan  ~/Downloads                 # 보기만
$H fix   ~/Downloads --apply         # 실제 정리
$H undo                              # 되돌리기
$H zip   ~/Downloads -o 제출본.zip    # 윈도우 안전 압축
$H unzip 제출본.zip                  # 이름 복원하며 해제
$H zipcheck 받은파일.zip             # 이 압축이 안전한지 검사
$H watch --status                    # 감시 상태
```

## 6. 끄기 / 삭제

- **잠깐 멈추기**: 메뉴 막대 아이콘 → `일시정지`, 또는 설정 → `일시정지`
- **자동 시작 끄기**: 설정 → `로그인할 때 자동 시작` 끄고 저장
- **완전 삭제**: 설정에서 자동 시작을 끈 뒤 `HanFix.app`을 휴지통으로.
  남는 것은 `~/.hanfix/` 폴더(로그·설정·되돌리기 기록)뿐이며, 지워도 무방합니다.

---

## 7. 안전성에 대해

- **파일 내용은 절대 수정하지 않습니다.** 이름만 다룹니다.
- 이름을 바꾸기 전에 같은 파일인지(inode) 확인해서, 남의 파일을 덮어쓰지 않습니다.
- 모든 변경은 `~/.hanfix/journal.jsonl`에 기록되어 **되돌리기**가 가능합니다.
- 네트워크로 나가는 데이터가 없습니다. 텔레메트리도 없습니다.
